# Movie and music data

FRAME uses live movie metadata when a provider is reachable. It does not host or stream full films.

## Music discovery and playback

The **Listen** tab uses public iTunes song metadata and current chart feeds. Recent releases are chart entries released within the last 365 days, sorted by their actual catalog release date; this is a selection, not an exhaustive new-release feed. Hindi uses the Bollywood genre chart (`1263`), Bengali uses the Bengali genre chart (`100046`), and English uses selected English-language artists in the US chart. Search accepts song titles and artist names, including Hindi and Bengali script, within the selected language shelf. The API omits songs without sufficient genre or selected-artist evidence because Apple's public metadata has no definitive sung-language field. Storefront country alone never determines language.

`GET /api/music?language=en|hi|bn&q=...` returns song metadata, provider links, release dates, and an explicit availability notice. Queries are limited to 120 characters. A bounded server cache retains successful catalog responses for ten minutes and coalesces identical requests; outages return an empty unavailable result with a retry option. Historical search matches are allowed, while recent shelves exclude old, future, and invalid dates.

Selecting a song loads the official `embed.music.apple.com` player. Playback starts through Apple's controls. Signed-out listeners receive previews; full tracks require eligible Apple Music subscription access. FRAME does not fetch, download, or rehost song audio. Each song links to Apple Music and an explicitly labeled YouTube Music search. Closing the player or leaving Listen removes the iframe and stops its playback. The existing original ambient soundscapes remain a separate feature and stop when Listen opens.

Official references: [Apple's embeddable player and playback behavior](https://artists.apple.com/support/1117-apple-music-marketing-tools), [iTunes Search API](https://performance-partners.apple.com/search-api).

## TMDB (recommended)

Set `TMDB_READ_ACCESS_TOKEN` to your TMDB API Read Access Token in the Sites environment, or `.env.local` for local development. The token stays on the server. Deploy again after changing hosted environment variables.

The app uses TMDB's `/3/trending/movie/week`, `/3/movie/now_playing`, `/3/movie/upcoming`, `/3/movie/top_rated`, `/3/discover/movie`, `/3/search/movie`, and `/3/movie/{id}?append_to_response=videos` endpoints. Country selects the release region; it does not guarantee local streaming availability. Upcoming covers today through the next 120 days; latest covers the preceding 45 days. Industry browsing uses Discover with `with_original_language=hi` for Bollywood, `bn` for Bengali, and `en` for Hollywood; the latter is an English-language cinema grouping, not a claim that every title was produced in Hollywood. Discover applies genre and regional theatrical release type/date filters together. Industry search filters TMDB's actual `original_language` value, rather than the language in which metadata is displayed. Bengali cinema includes Bengali-language originals from any country, including India and Bangladesh; selecting a release region never changes a title's original language. Data refreshes from the provider at most every 10 minutes for each industry/filter/search/region combination.

Official references: [application authentication](https://developer.themoviedb.org/docs/authentication-application), [now playing](https://developer.themoviedb.org/reference/movie-now-playing-list), [image URLs](https://developer.themoviedb.org/docs/image-basics), [TMDB attribution](https://developer.themoviedb.org/docs/faq).

This product uses the TMDB API but is not endorsed or certified by TMDB. Film artwork belongs to its respective rights holders.

## Apple iTunes (no API key)

Without a TMDB token, the app tries Apple's movie catalog. Search calls `https://itunes.apple.com/search` with `media=movie`, `entity=movie`, a country code, and the search term. Browsing calls the legacy `https://itunes.apple.com/{country}/rss/topmovies/limit=100/json` chart feed. Bollywood uses the corresponding `genre=4431` chart in the selected country. The latest tab includes only catalog films dated within the preceding 180 days and excludes future dates; unfiltered browsing first tries a current-year search and uses the chart when that search is empty. When a storefront's search is empty, the app filters the live chart instead; matching editorial picks are identified as curated if the chart also has no matches. Movie details use `https://itunes.apple.com/lookup?id={id}&entity=movie`.

Apple's Search/RSS schema does not expose original language. Industry selections therefore use a bounded registry of verified title/year pairs, including the editorial collection and its Bengali-script/English title aliases, to identify Hindi, Bengali, and English originals. Unknown language is not guessed from storefront country or the broad Bollywood genre. Explicit dubbed/audio-version labels are excluded from this registry rather than being treated as proof of original language. For example, the Bollywood chart can contain the Telugu original *Baahubali* dubbed in Hindi and the Marathi original *Sairat*; neither is accepted as a Hindi original. Search and genre filters still apply inside the selected industry. Coverage is intentionally limited and explained in the API's `notice`; selecting India as a region does not automatically turn all movies into Bollywood. A regional chart without matching verified entries falls back to the labeled editorial collection. When a latest chart has no verified recent Bengali originals, the Bengali shelf returns editorial picks with `live: false` and an explicit notice that these are not current releases. Other latest shelves remain empty when no recent titles match.

Apple's chart contains popular store movies, not a comprehensive list of theatrical releases or critic scores. The top-rated tab therefore identifies this fallback as a chart. Upcoming theatrical release data requires TMDB. Apple limits the Search API to approximately 20 requests per minute; the app uses server caching and a six-second timeout per request. Availability of the legacy chart feed can change.

Posters and previews promote their matching Apple store title. Detail pages link to the supplied store URL. Video previews are streamed on demand and never downloaded. Previews provided courtesy of iTunes. See [Apple's Search API documentation and promotional-content terms](https://performance-partners.apple.com/search-api).

## Offline editorial collection

If the configured live service fails, the API returns the included 40-film editorial collection with `live: false`, `source: "Curated collection"`, and an explanation, preserving the selected industry, genre, and title search. It includes 12 Hindi-language originals exported separately as `BOLLYWOOD_MOVIES` and 12 Bengali originals in `BENGALI_MOVIES`. These films are not described as current releases. Ratings are `null` because no live review provider has supplied them. Historical release dates may vary by territory; Bengali seeds retain the verified year and leave `releaseDate` empty when no day/month has been verified. Upcoming is empty when live upcoming data is unavailable, rather than relabeling older films. `updatedAt` is the provider-fetch or fallback-generation time, not a guarantee that the provider updated each title at that instant.

The included high-resolution movie artwork uses TMDB's public image CDN. The local `public/arrakis-hero.jpg` is a Dune: Part Two promotional VFX still, supplied by [DNEG](https://www.dneg.com/news) from [its public media library](https://images.ctfassets.net/3sjsytt3tkv5/2umXEBNgFkvvOJy5rHHjB3/ca52aecc1b3c0a66b3395b196a95b73c/Dune_Part_Two_-_VFX_still__Paul_and_crowd_.jpg); the film belongs to its respective rights holders. Fallback trailers link to official promotional videos on YouTube. Videos and images remain subject to their hosts' availability and playback policies. Respect each content provider's terms before commercial deployment.

## Bengali editorial sources

The Bengali shelf uses real distributor artwork and English/transliterated/Bengali-script title aliases. Language classification always prefers original-language metadata over a saved industry tag. Search normalizes Unicode without removing Bengali vowel marks. A matching Bengali title alone cannot turn a Hindi or English original into Bengali cinema.

Classic films use Criterion's verified Bengali-language editions, years, runtimes, cover art, and gallery stills: [Pather Panchali](https://www.criterion.com/films/28021-pather-panchali), [Charulata](https://www.criterion.com/films/28447-charulata), [Aparajito](https://www.criterion.com/films/28443-aparajito), [Apur Sansar](https://www.criterion.com/films/27905-apur-sansar), [Mahanagar / The Big City](https://www.criterion.com/films/28448-the-big-city), [Jalsaghar / The Music Room](https://www.criterion.com/films/27657-the-music-room), and [Devi](https://www.criterion.com/films/27906-devi). Runtimes refer to those distributor editions and can differ from historical prints. The unaltered 1200×900 `public/bengali-hero.jpg` is a Pather Panchali still from [Criterion's film gallery](https://s3.amazonaws.com/criterion-production/carousel-files/ba16466dc09a05120669b51aacad3d65.jpeg).

Modern films use SVF's official promotional art, production stills, and embedded theatrical trailers: [Baishe Srabon](https://svf.in/movie/baishe-srabon/), [Chander Pahar](https://svf.in/movie/chander-pahar/), [Rajkahini](https://svf.in/movie/rajkahini/), [Hemlock Society](https://svf.in/movie/hemlock-society/), and [Autograph](https://svf.in/movie/autograph/). Where no verified portrait poster was supplied, the matching film's promotional image is used. Their years and runtimes were checked against Hoichoi's corresponding film listings: [Baishe Srabon](https://hoichoi.tv/films/title/baishe-srabon), [Chander Pahar](https://hoichoi.tv/films/title/chander-pahar), [Rajkahini](https://hoichoi.tv/films/title/rajkahini), [Hemlock Society](https://hoichoi.tv/films/title/hemlock-society), and [Autograph](https://hoichoi.tv/films/title/autograph). All 12 poster links and supplied remote backdrops returned HTTP 200 when checked on 15 November 2026. The five trailer titles and SVF publisher were verified through YouTube oEmbed; classic trailers are omitted where no verified official trailer was selected. Artwork and films belong to their respective rights holders.
